이건 실제 사이트가 아니라 배경 스타일만 확인하는 시안입니다 — 마커·팝업·줌·비교표 연동 같은 지금 기능은 아직 하나도 없고, "지도가 콘타맵/도면 같은 분위기로 보이면 어떤 느낌인지"만 빠르게 보기 위한 것입니다. 실제 QGIS 지형 데이터가 아니라 Mapbox가 기본 제공하는 전 세계 등고선 데이터(진짜 고도 기반)를 씁니다. (액세스 토큰은 이미 넣어뒀습니다 — 바로 아래 지도가 보이면 정상입니다.)
Mapbox 액세스 토큰이 아직 입력되지 않았습니다.

1. mapbox.com 에서 회원가입(무료, 카드 필요 없음)
2. 로그인 후 Account → Tokens 에서 기본 토큰 복사
3. 이 파일을 텍스트 편집기로 열어서 아래 자리에 붙여넣기: mapboxgl.accessToken = "YOUR_MAPBOX_TOKEN_HERE"; 저장 후 다시 열면 지도가 보입니다.
