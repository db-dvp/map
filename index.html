이건 실제 사이트가 아니라 배경 스타일만 확인하는 3D 시안입니다 — 마커·팝업·줌·비교표 연동 같은 지금 기능은 아직 하나도 없고, "지도를 입체로 기울여서 지형이 실제로 튀어나오게 보이면 어떤 느낌인지"만 빠르게 보기 위한 것입니다. 실제 QGIS 지형 데이터가 아니라 Mapbox가 기본 제공하는 전 세계 고도 데이터(진짜 표고 기반)로 지형을 세웠고, 건물도 높이대로 입체로 세웠습니다. 시점 회전은 아래 "회전" 버튼을 쓰시거나, 마우스 휠(가운데) 버튼을 누른 채 드래그하면 스케치업처럼 자유롭게 돌아갑니다. Shift + 휠버튼 드래그는 회전 대신 화면을 이동시킵니다(오른쪽 버튼 드래그·두 손가락 드래그도 계속 됩니다). 아래 "드론 비행"은 지점들을 자동으로 순회하며 카메라가 날아다니는 연출입니다. 인천계양은 실제로 조사한 6개 단지(엘리움·박촌 풍림아이원·코아루 센트럴파크·효성해링턴 플레이스·힐스테이트 자이 계양·롯데캐슬 파크시티)를 순서대로 도는 실제 좌표이며, 롯데캐슬 파크시티만 미착공이라 설계 스펙 기반 근사 매스로 표시했습니다. 부산·전국은 아직 실제 조사·순위 데이터가 아니라 화면 데모용 샘플 좌표입니다.
